# GitLab MCP

Works with GitLab. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/@modelcontextprotocol/server-gitlab

Installs from the Camillia hub as `gitlab-mcp-4baff9`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
